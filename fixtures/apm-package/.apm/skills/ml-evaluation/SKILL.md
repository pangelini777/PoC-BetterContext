# ML evaluation

Use only when a machine-learning model or AI decision pipeline changes. Distractor otherwise.

1. Pin datasets, artifacts, and evaluation code before measuring.
2. Report slice metrics, not just aggregate scores.
3. Compare against the previous baseline on identical data.
4. Record reproducibility details so a third party can rerun the evaluation.
