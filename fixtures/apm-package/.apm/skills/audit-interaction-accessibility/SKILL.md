# Accessibility audit

Use after changing a web interaction to verify accessibility.

1. Check semantic HTML: headings, landmarks, lists, and form associations.
2. Verify every interactive control has an accessible name.
3. Tab through the flow: visible focus, logical order, no keyboard traps.
4. Confirm dialogs manage focus on open and restore it on close.
5. Confirm status and error messages are announced to assistive technology.
6. Report failures as a checklist with file and line references.
