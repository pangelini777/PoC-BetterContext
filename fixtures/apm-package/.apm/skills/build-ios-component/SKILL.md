# iOS SwiftUI component

Use only for native iOS SwiftUI work. Distractor for web tasks.

1. Follow Apple Human Interface Guidelines for navigation and layout.
2. Support Dynamic Type and VoiceOver from the start.
3. Use Swift concurrency correctly; keep UI updates on the main actor.
4. Do not import web payment or server-route patterns into native code.
