# Brand copy review

Use when writing or changing customer-facing product copy.

1. Prefer short, concrete verbs over marketing adjectives.
2. State only what the product does today; remove premature or unsupported claims.
3. Keep button labels action-oriented and consistent with surrounding flow.
4. Match existing capitalization and punctuation conventions.
5. Flag any copy that promises payment, delivery, or timing guarantees.
